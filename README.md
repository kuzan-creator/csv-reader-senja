CSV Senja is a fast drop-in for csv-reader 1.0.0: it reads broken CSV files exactly as the reference does — same columns, rows and errors on every case — but in slices instead of one character at a time, so it answers in a fraction of the reference's CPU time.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
